7. Le cycle, en une phrase

Le systeme pose 9 questions une seule fois, le proprietaire repond en une dizaine de minutes, et le systeme reprend seul : instanciation des variables, ecriture des deux registres, recalcul des echantillons, changement de statut. Aucune intervention ensuite pour les taches techniques.

8. Colab : reponse a la question posee

Kaggle : oui, controlable a distance. Le CLI officiel cree-ou-met-a-jour un kernel et le lance. Les tokens KGAT... sont documentes pour les "automated scripts, notebook workflows, CI/CD". Un serveur MCP distant officiel expose le statut et le telechargement des sorties. Un systeme muni d'un token peut donc le piloter sans navigateur.

Colab : partiellement. Le MCP officiel est lie a l'onglet du navigateur et exige un client local. Un fork communautaire execute sans onglet, mais il n'est pas officiel et le runtime meurt quand meme a 12 h ou a l'inactivite. C'est un fallback, pas un pivot.

Dans les deux cas, le token est revocable en un clic, contrairement a un mot de passe. Je ne detiens jamais vos tokens : le secret reste dans votre depot prive.
