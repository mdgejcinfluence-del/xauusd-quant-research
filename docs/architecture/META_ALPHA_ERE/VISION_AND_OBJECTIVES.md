# META ALPHA ERE — VISION ET OBJECTIFS (v1.0)

## Vision

META ALPHA ERE (Economic Reverse Engineering) est l'infrastructure qui
transforme des informations limitées sur un trader ou un robot — parfois
3 à 6 transactions, une biographie, des statistiques publiques — en
**modèles économiques identifiés et vérifiés indépendamment**, puis en
instruments d'exploitation propres. Le trader est une source
d'information sur les opportunités du marché, jamais un modèle à copier.

## Objectifs

1. Ingérer des dossiers traders incomplets sans inventer ce qui manque.
2. Reconstruire les comportements observables en séparant faits et interprétations.
3. Générer plusieurs hypothèses économiques concurrentes et nouvelles.
4. Concevoir les expériences les plus informatives pour les départager.
5. Rechercher leurs signatures dans le corpus certifié (685 118 625 ticks, 348 partitions, 2010-01-04 → 2026-09-30).
6. Identifier les mécanismes avec des verdicts qualifiés (DÉMONTRÉ → RÉFUTÉ).
7. Ne construire des moteurs indépendants qu'à partir de mécanismes suffisamment établis, avec nos propres règles.
8. Valider l'edge net après coûts sur données indépendantes et constituer un portefeuille de sources réellement différentes.

## Non-objectifs

Copier des entrées, retrouver un code source, identifier chaque
paramètre interne, accumuler des transactions sans question, optimiser
jusqu'au positif artificiel. Un résultat du type « trois mécanismes
restent compatibles, voici les expériences qui les départageraient »
est une **réussite scientifique** de ce système.

## Actif construit

Le moteur de reverse engineering économique lui-même : chaque nouveau
trader est un dossier traité par la même architecture, et chaque
dossier enrichit la bibliothèque de modèles (ME-001, ME-002, …).

## Principes directeurs

économique ; trois questions obligatoires ; jamais VALIDATED sur les
données de construction ; garde-fou anti-dérive avant toute mission ;
