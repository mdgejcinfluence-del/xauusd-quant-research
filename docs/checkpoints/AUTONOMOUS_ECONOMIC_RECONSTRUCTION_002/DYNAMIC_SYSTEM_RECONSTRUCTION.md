# RECONSTRUCTION COMME SYSTÈME DYNAMIQUE

État = (contexte de marché, inventaire du panier, prix moyen, PnL latent, temps
écoulé). Transitions observées/soutenues : contexte haussier + impulsion/frontière
→ ouverture ; prix favorable immédiat → clôture rapide (régime scalp, D/E) ; prix
adverse modéré → renforcement (recul ≈ −5 bp) ; retour vers le prix moyen →
clôture groupée ; clôture → réévaluation immédiate (B à +2 s). Deux régimes de
panier (immédiat / adverse-récupération) distingués par la trajectoire des 300
premières secondes. Variables latentes non identifiées : seuil d'abandon,
mémoire de capital, conditions d'arrêt des renforcements.
