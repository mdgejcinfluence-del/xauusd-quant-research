# PERFORMANCE ÉCONOMIQUE (objective B, séparée de la fidélité)

Moteurs gelés sur données réelles : janv.–sept. 2026 V1 −29,97 USD modèle ;
novembre V1 −0,432 / V2-F2 −0,930 ; aucun avantage après coûts (détail seq455/457).
Le mécanisme réel, lui, affiche une espérance par transaction positive sur son
profil (≈ +6,01 ¥, 49 595 transactions) — non reproductible ni vérifiable comme
rentabilité nette pour un suiveur (frais de performance 10 %, coûts propres,

rentabilité affichée du fournisseur ≠ mécanisme identifié.
