# REPLAY ET FIDÉLITÉ

Inchangés et revérifiés ce cycle : V1 4/5, V2-F2 5/5 entrées (en-échantillon,
±120 s) ; gestion partielle ; volumes/sorties non reproduits. Nouvel élément :
les deux régimes de trajectoire (immédiat vs adverse) fournissent un critère de
fidélité supplémentaire à appliquer aux futurs paniers réels — un moteur fidèle
devra produire les deux familles dans des proportions compatibles, ce qu'aucun
moteur actuel ne garantit. Fidélité comportementale et performance économique
restent mesurées séparément (rapports distincts).
