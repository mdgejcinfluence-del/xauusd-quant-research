# CONCLUSIONS SCIENTIFIQUES FINALES (DIRR-003)

Directement observé : trajectoires, PWA dynamiques, temps sous le PWA (65–88 %),
clôtures au voisinage du PWA, deux régimes de trajectoire. Mathématiquement
déduit : le renforcement abaisse le PWA et convertit l'excursion en écart de
sortie faible, contre une exposition accrue. Fortement soutenu (faible n) :
accumulation en excursion adverse dans un contexte haussier + sortie de
récupération ; régime immédiat secondaire. Candidat : portail d'entrée, unicité
F2, seuils de capture. Non identifiable : sizing, déclencheur de sortie exact,
risque réel, causalité du renforcement. Réfuté : premier retour PWA, marge fixe,
frontières M15, cible monétaire stricte, progression fixe des lots, mécanismes
directionnel/tendance/retour-à-la-moyenne purs. La reconstruction complète
reste impossible sur le corpus actuel — pour des raisons d'identification
désormais précises, pas faute d'avoir cherché.
