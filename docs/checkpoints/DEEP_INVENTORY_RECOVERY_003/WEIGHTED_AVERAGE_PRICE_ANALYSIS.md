# ANALYSE DU PRIX MOYEN PONDÉRÉ (PWA)

Le PWA est le centre géométrique du mécanisme : chaque renforcement adverse le
déplace vers le marché, transformant une excursion de −15 bp (vs première entrée,
cas C) en un écart de sortie de −0,25 bp (vs PWA). Mais le temps contredit le
déclencheur simple : les paniers passent 65–88 % de leur vie sous le PWA et le
franchissent plusieurs fois avant de clôturer. Mécanismes de sortie testés :
retour au PWA (RÉFUTÉ comme déclencheur), PWA + marge fixe (RÉFUTÉ), monétaire
strict (RÉFUTÉ, C), accélération/épuisement/durée/volatilité (INSUFFICIENT_DATA).
Rôle retenu : **référence de mesure de la récupération, pas horloge de sortie**.
Le seuil économique réel inclut les coûts (≈4–4,5 bp l'aller-retour documenté) :
clôturer exactement au PWA garantit une perte nette — ce que C illustre (−6 ¥).
