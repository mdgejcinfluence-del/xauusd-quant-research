# PROTOCOLE DE VALIDATION INDÉPENDANTE

Modèles gelés : V1 et V2-F2 (empreintes seq455/459). Toute observation nouvelle :
(1) archivage immuable + SHA-256 ; (2) déduplication par clé composite ;
(3) regroupement en paniers selon la règle documentée ; (4) classement AVANT
comparaison (cas discriminants seq443/447/449 : frontière/impulsion/fond, unicité
F2, renforcements, clôture) ; (5) comparaison aux moteurs gelés sans retouche ;
(6) publication des écarts, y compris défavorables. Statut INDEPENDENTLY_VALIDATED
exige une fidélité maintenue sur ces observations jamais utilisées pour construire
les règles ; un score global n'est publié qu'avec un effectif suffisant, sinon
les cas sont rapportés un par un.
