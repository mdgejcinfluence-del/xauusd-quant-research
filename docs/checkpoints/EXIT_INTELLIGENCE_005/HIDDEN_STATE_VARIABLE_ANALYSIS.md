# VARIABLES D'ÉTAT CACHÉES

Candidates examinées : résultat du panier précédent (B suit A gagnant : réentrée
à +2 s — compatible avec un réarmement sans délai, 1 cas) ; temps depuis la
dernière clôture (C/D/E aux frontières suivantes — confondu avec l'horloge M15) ;
temps sous l'eau et progrès de récupération (intégrés à la famille de sortie) ;
régime de volatilité, spread pré-entrée (homogène 1,21–1,43 bp, non discriminant).
Aucune variable cachée supplémentaire n'est identifiable : chacune exigerait des
paniers indépendants où elle varie indépendamment des autres.
