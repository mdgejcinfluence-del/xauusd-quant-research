# PARAMÈTRES DE SORTIE NON IDENTIFIÉS

Seuil d'état exact ; durée/mécanisme de confirmation (persistance, cadence
d'évaluation ou condition supplémentaire — observationnellement équivalents sur
5 clôtures) ; seuil de capture immédiate ; dépendance au nombre de positions ;
rôle de la volatilité. Raison mathématique : les clôtures n'observent que le
premier instant où la condition *complète* est remplie ; toute décomposition
entre seuil et persistance qui produit les mêmes 5 instants est équivalente.
Seules des clôtures nouvelles, avec des trajectoires variées, peuvent séparer
ces composantes.
