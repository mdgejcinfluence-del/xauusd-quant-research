# PHASE 23-A — AUDIT BUDGET 0 FCFA ET LICENCES

- **FRED / ALFRED (Federal Reserve)** : accès libre, téléchargement et API gratuits, données publiques
  fédérales. Utilisable à 0 FCFA. C'est la seule source quantitative retenue.
- **BLS / BEA / Federal Reserve (calendriers et communiqués)** : publications officielles gratuites.
  Utilisables à 0 FCFA pour les timestamps et les valeurs de première vintage via ALFRED.
- **Consensus macroéconomique historique** : uniquement chez des fournisseurs commerciaux
  (sondages contemporains archivés sous licence). **Bloqué** à budget 0 ; toute reconstruction
  a posteriori est interdite.
- **CME Group (GC)** : données de marché licenciées ; la grille publique CME tarife le temps réel,
  le différé et l'historique (DataMine). **Bloqué** à budget 0 pour le prix/volume/open interest
  historique exploitable. Seuls le calendrier des échéances et les informations publiques de contrat
  sont utilisables.
- **DXY intrajournalier (ICE)** : licence commerciale. **Bloqué** ; l'indice quotidien FRED
  DTWEXBGS (J-1) est le substitut public, sans équivalence intrajournalière revendiquée.
- Aucun achat, aucun abonnement, aucune source payante introduite dans cette phase.
