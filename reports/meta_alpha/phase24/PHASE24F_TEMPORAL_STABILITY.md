# PHASE 24-F — STABILITÉ TEMPORELLE

La fréquence réelle du label augmente avec le score dans les deux populations (calibration :
0,578 → 0,591 → 0,694 → 0,770 ; évaluation : 0,453 → 0,570 → 0,615 → 0,747 → 0,846) : le
**classement prédictif est stable et monotone**. L'espérance S2, elle, est négative dans toutes
les classes évaluables de l'évaluation (−3,27 ; −1,86 ; −6,41 ; −1,46) et dans trois des quatre
classes sélectionnées de calibration (+3,28 ; −2,23 ; −5,90 ; −4,36) — la seule classe positive
de calibration devient négative en évaluation (−3,27) : **aucune monotonicité économique** et
une inversion de signe précisément sur la classe qui aurait pu sembler prometteuse.
