# FOURNITURE DE LIQUIDITÉ — CE QUE VAUT RÉELLEMENT LE +0,17 BP

Décomposition (N-EXP-01/02/04, 24 889 impulsions) : le fade gagne +0,14 à +0,17 bp **en moyenne**
et +1,2 à +1,7 bp **en médiane** (53-56 % de positifs) : beaucoup de petits reflux, une queue
adverse qui ronge la moyenne. Tout est acquis dès la première barre M15 : rebond de
microstructure, pas dérive lente. Par tercile de spread : quand le spread est large (3,61 bp),
le reflux brut monte à +0,75 bp — le fournisseur est mieux payé quand la liquidité est rare —
mais le reflux ne couvre toujours qu'une fraction de l'écart affiché ; le revenu du fournisseur
vient de l'écart lui-même, moins les fills adverses (le prix traverse son limite précisément
quand l'information arrive). Classification honnête : **observation directe** pour le reflux Mid ;
**simulation optimiste** pour toute captation par limites (fills supposés) ; **hypothèse non
vérifiable** pour la rentabilité d'un market making META ALPHA sans carnet, file ni markouts
d'exécution réels. Le rôle de preneur nous coûte ce revenu ; le changer exige un autre contrat
d'exécution (courtier + limites + mesures de fills), pas un meilleur signal.
