# QUI PAIE, POURQUOI — LES SIX QUESTIONS APPLIQUÉES

**Liquidité immédiate** : paie = le participant pressé (couverture, marge, rééquilibrage) ;
pourquoi = son coût d'attente dépasse le spread ; service = exécution certaine maintenant ;
reçoit = le fournisseur (spread − sélection adverse − inventaire) ; META ALPHA = seulement via
limites réelles chez un courtier, fills non mesurables dans notre corpus ; persistance = le
besoin d'immédiateté est structurel.
**Assurance variance** : paie = l'acheteur d'options (protection, gamma) ; pourquoi = sa perte
en cas de saut dépasse la prime ; reçoit = le vendeur delta-couvert (prime mesurée +2 pts
médiane, en compression) ; META ALPHA = options licenciées uniquement.
**Transfert de risque de couverture** : paie = le producteur/consommateur net ; reçoit = le
porteur futures (COT visible, règle instable chez nous).
**Liquidation forcée** : paie = le compte sous marge (il vend à tout prix) ; reçoit = qui fournit
la contrepartie pendant le stress ; identification ex ante impossible avec nos données.
**Comportement** : paie = le participant réactif tardif ; reçoit = qui lui fournit la liquidité ;
notre fade mesure le montant : ≈ le spread, déjà capté par les fournisseurs en place.
**Gestion de la dérive** : paie = notre propre position non confirmée ; reçoit = nous, en
tronquant (−31 bp évités en partie) ; c'est la seule ligne où META ALPHA est des deux côtés —
et la seule candidate en test prospectif.
