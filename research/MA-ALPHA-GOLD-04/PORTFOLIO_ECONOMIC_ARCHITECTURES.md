# ARCHITECTURES ÉCONOMIQUES COMPARÉES

A. **Gestion seule (actuelle)** : deadline prospective + hygiène d'exécution. Source : réduction
de perte, pas revenu. C'est l'architecture livrable aujourd'hui.
B. **Gestion + mesure des primes** : A + tableau de bord des primes (variance, hedging pressure)
pour décider sur chiffres l'ouverture d'un instrument. Aucun risque ajouté.
C. **Variance licenciée (conditionnelle)** : B + programme options séparé (risque défini
d'abord), si le fondateur accepte compte options + données. Source : prime d'assurance mesurée.
D. **Fourniture professionnelle** : rejetée à ce stade — bornes négatives sur impulsions
(P-EXP-01) et infrastructure absente.
E. **Empilements directionnels** : rejetés — trois activités déficitaires ne font pas un
portefeuille (GOLD-01/02/03).
Contribution incrémentale : seule C ajouterait une source de revenu *distincte* de A ; B est son
préalable documentaire. L'architecture recommandée est B maintenant, C sur décision.
